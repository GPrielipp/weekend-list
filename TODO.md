# Major Features

- Admin Page

  - add platoon and squad assignments through google sheet
  - change what days the weekend list is for
  - manually fix user's information

- Login Page

  - utilize google login

- Weekend Entry Page

  - user enter information for the weekend list
  - submit information to server to save

- View/Approve Entry Page (same framework for different levels)

  - view company
  - view platoon
  - view squad

- CDO Page
  - view people on weekend for given day
